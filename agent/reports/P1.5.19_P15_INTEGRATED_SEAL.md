# P1.5.19 — P1.5 Integrated Seal

## Purpose

Proves the entire P1.5 subsystem is coherent, trace-bound, evidence-bound,
limitation-bound, candidate-safe, and non-promotional.

This is a **seal patch**, not a new feature patch. It does not introduce
new capability, verifier, evaluation, or memory behavior.

## Cold-cache verification requirement

Cached pytest runs are NOT seal evidence. Cold-cache verification is required:

```bash
rm -rf .pytest_cache
find . -type d -name "__pycache__" -exec rm -rf {} +
pytest
```

The `ColdCacheVerificationReport` records whether this was done and
whether it passed. Without it, `P15IntegratedSealReport.passed` is False.

## Seal criteria

P1.5 is sealed when Aurel can prove:

1. A governed action can produce trace-bound evidence
2. Verification is normalized
3. Evaluation candidates are extracted
4. Evaluation runs with brain-aware diagnostics
5. Capability claims are bounded and context_verified
6. Operator feedback is signal/candidate-only
7. Memory candidates are proposed without commitment
8. No hidden promotion or false certainty exists

These states are **impossible**:
- Verified capability without trace/evidence/verifier/limitations
- Evaluation result without limitations
- Capability claim without scope/limits/evidence
- Operator feedback directly verifying capability
- Operator feedback overriding failed verifier
- Memory candidate committed as memory
- Memory candidate entering retrieval
- Skill created by P1.5
- Reflex created by P1.5
- Policy changed by P1.5
- AurelTraceLog bypassed as canonical truth
- Cached pytest accepted as seal proof
