# P1.4.6 — Self-Model Specification

**Phase:** P1.4.6  
**Status:** Implemented  
**Companion:** [P1.4 Scope Contract](P1.4_IDENTITY_AUTONOMY_SCOPE_CONTRACT.md), [P1.4 Agent Trust Constitution](P1.4_AGENT_TRUST_CONSTITUTION.md), [P1.4.5 Identity Prompt Context Compiler Spec](P1.4.5_IDENTITY_PROMPT_CONTEXT_COMPILER_SPEC.md)

---

## 1. Purpose

The Self-Model is Aurel's **honest, runtime-readable self-description layer**. It answers who Aurel is, which identity sources are active, what boundaries apply, and what capabilities are planned vs implemented vs verified — without granting authority or self-certifying capabilities.

---

## 2. Non-goals

Not implemented: Agent Identity Card, Autonomy Scale, Measured Autonomy Score, Evaluation Mirror, full capability evidence system, skill registry, memory graph, Policy Cards, Path Governance, Heretic Sandbox, runtime model router, LLM calls, world model, autonomous self-improvement.

---

## 3. Self-Model vs Identity Kernel

Identity Kernel defines immutable trust boundaries. Self-Model describes current runtime posture derived from kernel and sibling layers; it does not replace or modify the kernel.

---

## 4. Self-Model vs Persona Manifest

Persona defines expression behavior. Self-Model describes capability and limitation posture; it is not voice or style.

---

## 5. Self-Model vs Operator Contract

Operator Contract defines principal/delegate authority. Self-Model reflects that relationship but cannot grant authority.

---

## 6. Self-Model vs Agent Identity Card

Agent Identity Card (P1.4.7) will present identity externally. Self-Model is the internal honest machine-readable description.

---

## 7. Self-Model vs Autonomy Scale

Autonomy Scale (P1.4.8) will govern autonomy selection. Self-Model cannot change autonomy.

---

## 8. Self-Model vs Evaluation Evidence

P1.5 Evaluation Mirror will provide evidence-backed verification. Before P1.5, verified capabilities require explicit `evidence_ref`; none are claimed by default.

---

## 9. Source bundle

`SelfModelSourceBundle` binds five identity source hashes plus optional `identity_prompt_context_hash` from P1.4.5.

---

## 10. Capability status doctrine

Statuses: `planned`, `implemented`, `verified`, `unavailable`, `unknown`, `partial`, `experimental`.

- **planned** — roadmap, not implemented
- **implemented** — code/config exists, not P1.5-verified
- **verified** — requires `evidence_ref`
- Roadmap modules must not be marked `implemented` without runtime proof

---

## 11. Capability inventory

Minimum 15 capabilities from P1.4.1–P1.4.6 (`implemented`) and future phases (`planned`). All pre-P1.5 entries use `evidence_ref: null`.

---

## 12. Known limitations

Twelve honest runtime boundaries (no Evaluation Mirror, no Autonomy Scale, no memory graph, etc.) phrased as boundaries, not failures.

---

## 13. Evidence posture

Default: `evaluation_mirror_available=false`, `verified_capability_claims_allowed=false`, `evidence_system_phase="P1.5 planned"`, `default_capability_claim_status="implemented_or_planned_not_verified"`.

---

## 14. Validation rules

Policy validator enforces SM-001–SM-007 invariants and all honesty/boundary/required-section flags.

Model validator checks agent name, source hashes, required sections, capability honesty, evidence posture, and forbidden positive authority/consciousness/self-verification claims.

---

## 15. Hashing rules

Canonical dict → JSON (`sort_keys=True`, compact separators) → SHA-256. Source hash or capability status changes alter the self-model hash.

---

## 16. Attestation behavior

`build_self_model_attestation()` / `write_self_model_attestation()` — explicit write only via CLI `--write` or tests.

---

## 17. CLI usage

```bash
python -m agentic_runtime.cli identity self show --json
python -m agentic_runtime.cli identity self validate
python -m agentic_runtime.cli identity self hash
python -m agentic_runtime.cli identity self capabilities --json
python -m agentic_runtime.cli identity self limitations --json
python -m agentic_runtime.cli identity self attest --json
```

Optional `--prompt-mode FOCUS` binds P1.4.5 context hash.
