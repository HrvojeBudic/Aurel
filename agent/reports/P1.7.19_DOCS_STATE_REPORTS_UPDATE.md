## 5. Shadow-Only Boundaries

- **P1.7.10** — `resolve_path_governance_shadow()` produces `WOULD_*` recommendations with `shadow_only=true` and `enforced=false`. Does not block paths, mutate sources, or call policy.
- **P1.7.11** — `resolve_source_trust_shadow()` produces advisory `recommended_trust_label` with `shadow_only=true` and `enforced=false`. Does not mutate source trust taxonomy or identity.
- **P1.7.12** — `resolve_path_source_conflicts_shadow()` produces advisory conflict/precedence signals with `shadow_only=true` and `enforced=false`. Does not enforce precedence or resolve conflicts at runtime.

---

## 6. Trace/Ledger Boundaries

- **P1.7.13** — `record_path_resolution_trace_hook()` builds deterministic trace payloads with `PAYLOAD_ONLY` default mode. Optional injected sink for tests. `ledger_written=false`. Does not emit to global AurelTrace spine by default.
- **P1.7.14** — `record_path_violation_trace_hook()` builds observational violation/drift payloads. Evidence only — no correction, rollback, or repair. `ledger_written=false`, `enforcement_triggered=false`. Does not write Ledger or emit global trace by default.

---

## 7. Policy/Custos Boundaries

- **P1.7.16** — `bridge_path_governance_to_policy_context()` produces advisory `PathPolicyContextPacket` with `policy_called=false`, `policy_decision_made=false`, `approval_created=false`. Context packet only — does not invoke policy engine or Custos runtime.
- No policy runtime/Custos enforcement exists in P1.7. Policy integration deferred to later phases (P9/P25).

---

## 8. Projection/CLI Boundaries

- **P1.7.17** — `PathGovernanceReadModel`, `PathGovernanceApiEnvelope` are read-model/API envelope objects. Not an HTTP server, FastAPI route, or Flask route. Shell binding remains UNAVAILABLE.
- **P1.7.18** — `handle_path_governance_cli_request()` is read-only terminal inspector over P1.7.17 projection. All `PathGovernanceCliSideEffects` booleans false. Not a control plane, not runtime command execution, not Shell UI.
