# P0.17.1 — Pre-P0.20 Readiness Patch Report

**Date:** 2026-06-17

## Summary

Fixed five concrete readiness bugs discovered before P0.20: missing-file crashes in
repo context building, test runner contract mismatch, AutoApprover predicate widening,
explicit repo auto-approval envelope, and pytest collection warnings.

## Bugs fixed

1. **RepoContextBuilder missing README** — only include `pyproject.toml` / `README.md` when they exist; `_summarize_file` returns `skipped_reason="missing file"` defensively.
2. **TestRunnerAdapter contract** — list commands (pytest, `python -c`) route through `run_tests` with `{"command": [...], "timeout_seconds": ...}` instead of invalid `run_shell` list arg.
3. **AutoApprover predicate widening** — predicate can narrow approval, never widen beyond `allow_r*` flags.
4. **Repo auto approval envelope** — explicit `allow_r4=False`, `allow_r5=False` in `_approval_gate_for`.
5. **Pytest collection warning** — `__test__ = False` on `TestRunResult`, `TestRunnerAdapter`, `TestFailureAnalyzer`.
