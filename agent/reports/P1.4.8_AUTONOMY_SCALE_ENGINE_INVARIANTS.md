# P1.4.8 — Autonomy Scale Engine Invariants

**Date:** 2026-06-21  
**Status:** Active

## Invariants

| ID | Invariant | Enforcement |
|----|-----------|-------------|
| INV-P148-01 | Autonomy is action-scoped, never global. | `AutonomyRequest` is scoped to a single action. No global autonomy field exists on `AutonomyDecision`. Resolver never computes an aggregate. |
| INV-P148-02 | A7 means denied, not elevated autonomy. | `is_denied()` helper. A7 decisions have `allowed=False`. `_AUTONOMY_NUMERIC[A7] = -1`. Invariant enforcement rejects `allowed=True` with A7. |
| INV-P148-03 | Unknown risk/reversibility/action class fails closed. | `resolve_autonomy_decision()` returns A7_DENIED for None risk/reversibility tiers and UNKNOWN action category. |
| INV-P148-04 | Authority scope is required for any action beyond suggestion. | `_check_authority_scope()` gates ANSWER/SUGGEST minimally; beyond those, operator contract's execution_authority is consulted. |
| INV-P148-05 | High-risk external effects require human approval. | HIGH_RISK and EXTERNAL_EFFECT actions force `requires_human_approval=True` and add `human_approval_required` gate. R4_CRITICAL without escalation path → A7_DENIED. |
| INV-P148-06 | Planned/roadmap-only capability cannot authorize action. | `_check_capability()` returns False for `planned`, `roadmap`, `roadmap_only` status entries. |
| INV-P148-07 | AutonomyDecision must be explainable. | Every decision carries a `reason` string. Invariant enforcement rejects empty reason. |
| INV-P148-08 | AutonomyDecision must expose blockers. | Denied decisions must have non-empty `blockers` tuple. Invariant enforcement rejects `allowed=False` with empty blockers. |
| INV-P148-09 | P1.4.8 does not execute tools. | Resolver is pure logic — returns `AutonomyDecision`, never dispatches tool handlers. |
| INV-P148-10 | P1.4.8 does not compute global Measured Autonomy Score. | No aggregate/measured/global scoring exists in the module. Serialized decisions have no `global_score`/`aggregate_score`/`measured_autonomy` keys. |
