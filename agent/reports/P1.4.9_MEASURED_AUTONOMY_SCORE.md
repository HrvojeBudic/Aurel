## 1. Summary

P1.4.9 implements an evidence-backed measurement layer that summarizes autonomy behavior from `AutonomyDecision` records. It measures — does not grant — autonomy. No global autonomy percentage is computed.

## 6. Measured autonomy classes

INSUFFICIENT_EVIDENCE → DENIED_OR_UNTRUSTED → ANSWER_ONLY → DRAFT → LOCAL_REVERSIBLE → GOVERNED_TOOL → CONDITIONAL → APPROVAL_GATED_HIGH_RISK

## 7. Decision record source

JSONL at `agent/state/autonomy_decisions.jsonl`. CLI `--evaluate-and-record` evaluates + stores in one step.

## 8. Score logic

Filter → count → distributions → highest_verified (no-blocker-only) → classify → confidence.

## 9. Fail-closed

0/insufficient records → INSUFFICIENT_EVIDENCE. A7 excluded from order. Invalid JSONL silently skipped. No permissions fields.

## 10. Healthy vs unhealthy denials

Surfaced via `top_blockers`. Healthy: authority_scope, high_risk, external_effect. Unhealthy: missing_operator_contract, capability_not_implemented, unknown_tier.

## 11. CLI usage

```bash
python -m agentic_runtime.cli identity autonomy measure --json
python -m agentic_runtime.cli identity autonomy measure --evaluate-and-record --action-category draft --action-name test --risk-tier R1_LOW --reversibility-tier R1_FULLY_REVERSIBLE --json
```
