# P1.5.1 — Evaluation Object Model

**Date:** 2026-06-21 | **Status:** COMPLETE (READY)

## 1. Summary

P1.5.1 defines the stable evaluation result language for Aurel: status, outcome, verdict, confidence class, evidence quality, failure modes, criterion-level results, full evaluation results, and result sets. Categorical semantics only — no numeric capability scoring.

## 5–11. Object model

| Type | Purpose |
|------|---------|
| EvaluationResultStatus | DRAFT, READY, COMPLETED, BLOCKED, INVALID, ERROR |
| EvaluationOutcome | PASSED, FAILED, PARTIAL, INCONCLUSIVE, BLOCKED, SKIPPED, ERROR |
| EvaluationVerdict | SUPPORTED, PARTIALLY_SUPPORTED, etc. — **no VERIFIED** |
| EvaluationConfidenceClass | NONE, LOW, MODERATE, HIGH, UNKNOWN — categorical only |
| EvaluationEvidenceQuality | NONE, WEAK, ADEQUATE, STRONG, CONFLICTED, STALE, UNKNOWN |
| EvaluationFailureMode | 18 modes including benchmark contamination/reward hacking (future-ready) |
| EvaluationCriterionResult | Per-criterion outcome with evidence refs |
| EvaluationResult | Full result with resolution from criteria |
| EvaluationResultSet | Categorical aggregation of multiple results |

## 12. Resolution rules

1. No criteria → INCONCLUSIVE / INSUFFICIENT_EVIDENCE
2. Any BLOCKED → BLOCKED
3. Any CONFLICTED → CONFLICTED
4. REQUIRED_CRITERION_FAILED → FAILED / REJECTED
5. All PASSED + adequate evidence → PASSED / SUPPORTED (not VERIFIED)
6. Mixed → PARTIAL / PARTIALLY_SUPPORTED
7. No usable evidence → INSUFFICIENT_EVIDENCE
