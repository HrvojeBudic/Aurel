## 5. Binding model

EvidenceClaimBinding maps CapabilityEvidenceRecord status/strength to claim impact semantics.

### Mapping rules
| Evidence Status | Evidence Strength | Relationship | Support Level |
|---|---|---|---|
| USABLE | STRONG | SUPPORTS | STRONG |
| USABLE | ADEQUATE | SUPPORTS | MODERATE |
| USABLE | WEAK | PARTIALLY_SUPPORTS | WEAK |
| CANDIDATE | ADEQUATE/STRONG | PARTIALLY_SUPPORTS | WEAK |
| INSUFFICIENT | any | INSUFFICIENT | NONE |
| CONFLICTED | any | CONFLICTS | NONE |
| STALE | any | WEAKENS (default) | NONE |
| EXPIRED | any | WEAKENS | NONE |
| REVOKED | any | BLOCKS | NONE |
| INVALID | any | BLOCKS | NONE |
| REJECTED | any | BLOCKS | NONE |

## 6. Default binding policy

- require_usable_evidence_for_support = True
- block_conflicted_evidence = True
- block_revoked_or_invalid_evidence = True
- allow_stale_evidence_to_support = False
- allow_single_evidence_to_verify_claim = False

## 7. Binding validation rules

- Empty binding_id/claim_id/evidence_id rejected
- BOUND cannot use UNKNOWN relationship
- SUPPORTS requires MODERATE/STRONG support
- SUPPORTS rejects HIGH/CRITICAL conflict
- SUPPORTS rejects INVALID/REVOKED/REJECTED/CONFLICTED evidence
- CONFLICTS requires conflict level > NONE or warning/blocker
- BLOCKS requires blocker or warning
- INVALID status requires blocker
- VERIFIED anywhere is forbidden

## 8. Binding aggregation rules

Dominance: BLOCKS > CONFLICTS > SUPPORTS > MIXED > INSUFFICIENT > STALE.

- No bindings → INSUFFICIENT
- Any BLOCKS/INVALID/REJECTED → BLOCKS
- Any CONFLICTS → CONFLICTED
- All SUPPORTS with STRONG → SUPPORTS/STRONG
- Mixed → PARTIALLY_SUPPORTS
- Stale-only → INSUFFICIENT/STALE

## 9. Optional EvaluationResult-to-claim binding

`bind_evaluation_result_to_claim()` was deferred per spec guidance ("If this function creates too much import/dependency complexity, skip and document it as a later extension"). The core `bind_evidence_to_claim()` is the required function.

## 13. Known limitations

- No EvaluationResult-to-claim binding (deferred to avoid import complexity)
- No claim object mutation — binding is purely referential (claim_id references only)
- No verification levels — binding decisions are inputs to later verification (P1.5.15)
- Stale evidence support requires policy override (default is deny)
- Single evidence cannot verify a claim (policy default is False)
