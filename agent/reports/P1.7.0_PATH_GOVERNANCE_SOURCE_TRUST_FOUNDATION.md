## 1. Purpose

P1.7.0 establishes the path governance vocabulary, source/trust label axes, closed-world validation, deterministic serialization, and honest capability reporting for the Path Governance Engine. It does **not** implement path resolution, enforcement, sandbox changes, CLI binding, projection contracts, trace hooks, policy bridge, or Ledger writes.

## 5. Label Summaries

### ProjectionSourceLabel (operator-visible truth)

| Label | Meaning |
|-------|---------|
| LIVE | Real backend/projection/runtime data |
| TRACE_VERIFIED | Trace/evidence hash present |
| SIMULATED | Dry-run/simulation |
| DEV_FIXTURE | Visible test/demo fixture |
| UNAVAILABLE | Not implemented — reason required |
| ERROR | Failed attempt — safe error info required |

P1.7.0 capability status uses **UNAVAILABLE** at foundation phase.

### SourceTrustLabel (content trust/origin — separate axis)

| Label | Meaning |
|-------|---------|
| TRUSTED | Known trusted origin |
| OPERATOR_PROVIDED | Operator-supplied content |
| INTERNAL_REPO | In-repo governed source |
| LOCAL_PRIVATE | Local private workspace content |
| TOOL_GENERATED | Tool/model generated output |
| EXTERNAL | External origin |
| UNTRUSTED | Explicitly untrusted |
| UNKNOWN | Origin not classified |
| QUARANTINED | Isolated pending review |

Projection labels and trust labels must never be conflated.
