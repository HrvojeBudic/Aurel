## 1. Purpose

P1.7.1 establishes stable, deterministic, JSON-safe, hash-ready path identity objects. It separates raw path input from normalized path representation and creates identity hashes future P1.7 resolver, trace, projection, and policy-bridge tasks can bind to.

Core law: path identity means represent, not authorize. Raw path is not authority. Canonical path is not permission.

## 3. Implemented

- `PathKind`: `REPO_RELATIVE`, `LOCAL_ABSOLUTE`, `LOCAL_RELATIVE`, `WORKSPACE_RELATIVE`, `UPLOAD_REF`, `VIRTUAL`, `UNKNOWN`
- `PathSensitivity`: `PUBLIC`, `INTERNAL`, `PRIVATE`, `SECRET_CANDIDATE`, `UNKNOWN`
- `CanonicalizationStatus`: `CANONICAL`, `NORMALIZED_ONLY`, `UNRESOLVED`, `UNSUPPORTED`, `ERROR`
- `PathRef`: preserves `raw_path`, declared kind/sensitivity, projection source label, JSON-safe metadata
- `CanonicalPathRef`: separates `raw_path`, `normalized_path`, `display_path`, status, warnings, `path_hash`, and `canonical_hash`
- `PathIdentity`: binds `PathRef` + `CanonicalPathRef` with deterministic `identity_hash`, `created_by_task="P1.7.1"`, `schema_version="path_identity.v1"`
- `build_path_identity()`: deterministic schema factory; no filesystem inspection or runtime authority
- Deterministic `path_hash`, `canonical_hash`, and `identity_hash` using P1.7.0 `stable_hash`
- Closed-world `from_dict()` validation for `PathRef`, `CanonicalPathRef`, and `PathIdentity`; unknown fields reject with `UNKNOWN_FIELD`
- Focused tests for imports, required values, raw/canonical separation, hash determinism, closed-world rejection, and non-enforcement boundaries
