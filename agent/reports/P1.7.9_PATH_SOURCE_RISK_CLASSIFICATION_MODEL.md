## 1. Purpose

P1.7.9 establishes deterministic, JSON-safe, hash-ready path/source risk classification objects. It summarizes declared risk signals from source trust, path boundary, authority scope, untrusted content boundary, and provenance/evidence context without resolver behavior, policy engine integration, approval activation, trace event emission, Ledger writes, or runtime enforcement.

Core laws:

- Risk classification is not resolver.
- Risk score is not deny.
- Risk level is not enforcement.
- Risk posture is not policy decision.

## 3. Implemented

- `PathSourceRiskLevel`: NONE, LOW, MEDIUM, HIGH, CRITICAL, UNKNOWN
- `PathSourceRiskSignalKind`: UNKNOWN_SOURCE, UNTRUSTED_SOURCE, QUARANTINED_SOURCE, EXTERNAL_SOURCE, TOOL_GENERATED_SOURCE, MODEL_GENERATED_SOURCE, PATH_TRAVERSAL_SIGNAL, OUTSIDE_TRUSTED_ROOT_SIGNAL, ABSOLUTE_PATH_WITHOUT_ROOT_CONTEXT, AUTHORITY_EXPANSION_SURFACE, PROMPT_INSTRUCTION_SURFACE, TOOL_ARGUMENT_SURFACE, MEMORY_WRITE_SURFACE, POLICY_DEFINITION_SURFACE, EXECUTION_REQUEST_SURFACE, LOW_CONFIDENCE_EVIDENCE, CONFLICTED_EVIDENCE, UNVERIFIED_CLAIM, MISSING_PROVENANCE, UNKNOWN
- `RiskClassificationBasis`: SOURCE_TRUST, PATH_BOUNDARY, TRUSTED_ROOT, AUTHORITY_SCOPE, UNTRUSTED_CONTENT_BOUNDARY, PROVENANCE_EVIDENCE, CLAIM_REFERENCE, SYSTEM_DEFAULT, TEST_FIXTURE, UNKNOWN
- `RiskClassificationPosture`: INFORMATIONAL, REVIEW_RECOMMENDED, REVIEW_REQUIRED_LATER, RESTRICTED_LATER, QUARANTINE_RECOMMENDED, UNKNOWN
- `PathSourceRiskSignal` with deterministic `signal_id`
- `PathSourceRiskClassification` with deterministic `classification_id` and `classification_hash`
- `PathSourceRiskRegistry` with order-insensitive deterministic `registry_hash`
- `build_path_source_risk_signal()`
- `build_path_source_risk_classification()`
- `build_path_source_risk_registry()`
- `derive_path_source_risk_classification()` — declarative max-risk and posture derivation from signals only
- Deterministic hash helpers: `compute_signal_id`, `compute_classification_id`, `compute_classification_hash`, `compute_path_source_risk_registry_hash`
- Source-label truth for risk classification state
- Closed-world validation; unknown fields reject with `UNKNOWN_FIELD`
- Focused tests (41) for exports, signal semantics, interop with P1.7.2–P1.7.8 references, hash determinism, non-resolver/non-enforcement boundaries, and no filesystem/network access
