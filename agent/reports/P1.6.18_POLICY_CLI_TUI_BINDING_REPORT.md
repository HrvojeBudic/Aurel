# P1.6.18 — Policy CLI/TUI Binding Report

**Status:** COMPLETE
**Date:** 2026-06-25
**Phase:** P1.6 — Policy Cards & Behavioral Contracts
**Predecessor:** P1.6.17 — Policy Projection/API/Event Contract
**Successor:** P1.6.19 — Policy Docs/State/Reports Update

## Purpose

P1.6.18 binds the P1.6 policy projection contract to a minimal operator-facing CLI/TUI surface; it does not enforce policy decisions, write to the Ledger, activate approvals, block commands, or change runtime sandbox behavior.

## Roadmap v5.1 Integration-First Requirement

This vertical slice delivers:

1. **Backend capability** — CLI consumes `build_policy_projection_contract(cli_binding_available=True)` from P1.6.17.
2. **Versioned contract/schema** — CLI requires `contract_version = policy_projection.v1`; fails safely with exit code 2 on build errors.
3. **Projection/API/CLI-readable state** — `policy status`, `policy projection`, and `policy unavailable` expose sections, source labels, readiness, unavailable reasons, errors, and `projection_hash`.
4. **Shell/CLI/TUI binding** — `policy` CLI command group added; Shell binding remains `UNAVAILABLE`.
5. **Trace/evidence/report binding** — projection displays trace/evidence hashes when present in contract sections; harness run exposes `report_hash`.

## Relationship to P1.6.17 Policy Projection/API/Event Contract

P1.6.17 defines the read model. P1.6.18 is a thin binding layer in `cli_modules/policy_commands.py` that calls `policy_projection_to_json_safe_dict()` and `format_policy_status_text()` — no parallel projection logic.

## CLI Command Surface

| Command | Description |
|---------|-------------|
| `policy status` | Text summary of policy projection contract |
| `policy status --json` | JSON projection payload |
| `policy projection` | Text projection (same as status) |
| `policy projection --json` | JSON-only projection output |
| `policy unavailable` | List UNAVAILABLE sections with reasons |
| `policy harness list` | List built-in harness case IDs |
| `policy harness run` | Run default harness suite |
| `policy harness run --case <id>` | Run single harness case |

## Contract Consumption Model

```
Operator → python -m agentic_runtime.cli policy *
         → cli_modules/policy_commands.py
         → build_policy_projection_contract(cli_binding_available=True)
         → policy_cards/projection_contract.py (P1.6.17)
```

Harness commands consume `policy_harness_registry.py` + P1.6.16 `run_policy_harness_suite` / `evaluate_policy_harness_case` / `build_policy_harness_report`.

## Source Label Display Model

Every displayed capability state preserves P1.6.17 source labels: `LIVE`, `TRACE_VERIFIED`, `SIMULATED`, `DEV_FIXTURE`, `UNAVAILABLE`, `ERROR`. After P1.6.18, `cli_binding` reports `LIVE`; `shell_binding` remains `UNAVAILABLE`.

## JSON/Text Output Format

- **Text:** `contract_version`, `Projection Hash: sha256:…`, top-level `Source`, per-section lines, `Readiness` flags, unavailable reasons, errors.
- **JSON:** canonical dict from `policy_projection_to_json_safe_dict()` with `sort_keys=True`, compact separators — no decorative text.

## Exit Code Model

| Code | Meaning |
|------|---------|
| 0 | Command succeeded |
| 1 | Harness run has FAIL results |
| 2 | Projection build / command runtime error |
| 3 | Invalid policy subcommand usage (when handler reached) |
| 4 | Unknown harness case_id |

Top-level argparse invalid command remains exit `2` (framework default).

## Harness Binding

- Built-in registry: `policy_harness_registry.py` with 14 scenarios ported from P1.6.16 integration matrix.
- `policy harness list` — case_id, title, source=LIVE.
- `policy harness run` — suite summary with report_hash, shadow_only_status, enforced=false.
- No comparator duplication in CLI module.

## Read-only / Non-enforcement Proof

- `policy_commands.py` does not import `runtime`, `approval`, `ledger`, or `sandbox`.
- No `AgenticRuntime.submit()` calls.
- Harness runs shadow validation only; `enforced: false` in all summaries.
- Projection build is read-only; registry/resolver/policy cards are not mutated.
