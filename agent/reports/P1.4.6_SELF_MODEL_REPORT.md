## 1. Summary

P1.4.6 implements Aurel's **honest runtime self-description layer**. The Self-Model loads policy from `config/aurel/self_model_policy.yaml`, validates P1.4.1–P1.4.5 identity sources, builds a hash-bound `AurelSelfModel` with identity summary, authority boundaries, capability-honest inventory, known limitations, evidence posture, and non-goals, and exposes CLI commands under `identity self`.

Self-Model describes reality. It does not grant authority, verify capabilities by itself, or write memory.

Canonical self-model policy hash: `2b2440ee1cd3db05eae3ecfdbedb7379c819253982852899b115133a3296623a`  
Example self-model hash (with FOCUS prompt context): `77e5732c64dec04011d373f62db18e4da7a6a5f7f49337484a6ad37e3e6f72f9`

## 3. Self-model policy summary

- `policy_class: honest_runtime_self_description`
- All source requirements mandatory
- All honesty flags true
- All boundaries false (cannot grant authority, change identity/autonomy, verify, write memory, modify policy)
- All required sections enabled
- SM-001–SM-007 critical invariants with `fail_build`

## 9. Validation rules implemented

Policy validator: applies_to_agent, policy_class, honesty, boundaries, required sections, capability statuses, invariant integrity.

Model validator: agent name, source hashes, required sections, capability honesty, evidence posture, forbidden positive authority/autonomy/consciousness/self-verification claims.

---

## 10. Hashing behavior

Deterministic SHA-256 over canonical JSON. Source hash, capability status, or limitation changes alter self-model hash.

---

## 11. Attestation behavior

`build_self_model_attestation()` binds self_model_hash to source hashes. Explicit write via CLI `--write` only.
