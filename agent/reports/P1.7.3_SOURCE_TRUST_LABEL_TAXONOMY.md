## 1. Purpose

P1.7.3 establishes stable, deterministic, JSON-safe, hash-ready source trust taxonomy objects. It defines what each `SourceTrustLabel` means, what each label may be used to interpret, and what each label must never imply.

Core law: trust taxonomy means define, not decide. A trust label is not permission, memory authority, prompt authority, command authority, resolver output, or enforcement.

## 6. Semantic Boundary Summary

- TRUSTED does not mean unlimited authority.
- OPERATOR_PROVIDED does not override policy.
- INTERNAL_REPO does not mean executable-safe.
- LOCAL_PRIVATE does not mean safe to expose.
- TOOL_GENERATED does not mean true.
- EXTERNAL can inform but cannot command.
- UNTRUSTED can be identified/cited but cannot command.
- UNKNOWN is explicit uncertainty, not implicit trust.
- QUARANTINED means restricted, not deleted.

## 7. Governance Boundary
