## 1. Purpose

P1.7.2 establishes stable, deterministic, JSON-safe, hash-ready source identity objects. It represents source kind, source origin, and minimal lineage seed references without resolving trust, granting authority, fetching URLs, reading files, scanning content, or binding provenance evidence.

Core law: source identity means represent, not trust. Source origin is not authority. Source hash is not truth.

## 3. Implemented

- `SourceKind`: `OPERATOR_INPUT`, `REPO_FILE`, `LOCAL_FILE`, `UPLOADED_FILE`, `EXTERNAL_WEB`, `TOOL_OUTPUT`, `MODEL_OUTPUT`, `AGENT_OUTPUT`, `MEMORY_ENTRY`, `PATH_REF`, `UNKNOWN`
- `SourceOrigin`: `OPERATOR`, `INTERNAL_REPO`, `LOCAL_MACHINE`, `UPLOAD`, `EXTERNAL_NETWORK`, `GOVERNED_TOOL`, `MODEL`, `AGENT`, `MEMORY`, `UNKNOWN`
- `SourceLineageRelationship`: `DERIVED_FROM`, `EXTRACTED_FROM`, `SUMMARIZED_FROM`, `UPLOADED_AS`, `GENERATED_BY`, `QUOTED_FROM`, `REFERENCES`, `UNKNOWN`
- `SourceRef`: deterministic source reference with source kind, origin, projection source label, trust label metadata, optional display name, optional URI/path, optional explicit content hash, and JSON-safe metadata
- `SourceLineageRef`: flat lineage seed reference with parent source ID, relationship, deterministic `lineage_hash`, optional notes, and metadata
- `SourceIdentity`: binds `SourceRef` + lineage refs with deterministic `identity_hash`, `created_by_task="P1.7.2"`, `schema_version="source_identity.v1"`
- `build_source_identity()`: deterministic schema factory; no network, filesystem, memory lookup, content scan, trust resolution, or runtime authority
- Deterministic `source_id`, `lineage_hash`, and `identity_hash` using P1.7.0 `stable_hash`
- Closed-world `from_dict()` validation for `SourceRef`, `SourceLineageRef`, and `SourceIdentity`; unknown fields reject with `UNKNOWN_FIELD`
- Focused tests for required values, source representation modes, lineage determinism, closed-world rejection, no network/filesystem reads, and non-enforcement boundaries
