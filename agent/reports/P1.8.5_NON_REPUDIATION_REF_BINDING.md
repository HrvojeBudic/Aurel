# P1.8.5 — Non-RepudiationRef Binding / Evidence Hook

**Date:** 2026-06-27
**Roadmap:** v5.1 Integration-First
**Status:** Complete (focused validation passed, committed locally)

## Purpose

Create a deterministic, versioned, JSON-safe, side-effect-free evidence/non-repudiation reference binding layer for delegation accountability. The evidence hook binds reference-only evidence, claim, attestation, signature, and trace references to DelegationRef / DelegationIdentity / DelegationRoleBindingSet / DelegationConstraintSet / DelegationAuthorityBindingSet without verifying evidence, proving claims, verifying signatures, verifying trace, claiming legal finality, writing Ledger, writing global trace, or creating Output Passport behavior.

## Remaining Risks / Limitations

1. **Evidence is reference-only** — No evidence truth verification. This is by design (P1.8.5 scope) but means that evidence refs carry no guarantee of authenticity.
2. **No cryptographic binding** — Hashes are deterministic but not cryptographically signed. This is P1.8.5 boundary.
3. **No trace integration** — Envelope has trace_refs but does not write to or verify against trace. This is P1.8.5 boundary.
4. **No non-repudiation proof** — The binding set hash exists but does not constitute non-repudiation proof. This is explicitly the core law of P1.8.5.
5. **Completeness profile is presence/absence only** — No trust scoring, confidence scoring, or validity assessment.
6. **No dispute resolution** — Dispute readiness status exists but no resolution mechanism.
