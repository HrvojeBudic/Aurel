# P1.4.10 — Capability Claim Boundary Engine Report

## 1. Summary

P1.4.10 introduces the **Capability Claim Boundary Engine**, an anti-hype firewall that prevents Aurel from claiming capabilities beyond evidence. It evaluates capability claims against available evidence, determines allowed status, blocks overclaims, and generates safe truthful rewrites when claims are blocked or downgraded.

This patch does NOT implement new capabilities, grant new autonomy permissions, or execute tools. It is a governance primitive that constrains what can be truthfully claimed about existing, experimental, or planned capabilities.

## 10. Evidence Requirements

Key rules enforced by the engine:
- Global autonomy claims → FORBIDDEN (safe rewrite: "action-scoped autonomy evaluation")
- Self-improvement claims → FORBIDDEN without verified promotion evidence
- Production-ready claims → FORBIDDEN before P20 seal
- ABOS deployment claims → FORBIDDEN before P21.8
- AETHER multimodal claims → FORBIDDEN before P19
- Sandbox claims → ROADMAP_ONLY before P9
- Action-scoped autonomy evaluation → ALLOWED (PARTIALLY_VERIFIED) given P1.4.8/P1.4.9 evidence

## 11. Safe Claim Rewriting

Safe rewrite must:
- Preserve truth (not lie)
- Not soften a forbidden claim into a misleading claim
- Clearly distinguish roadmap/planned from implemented/verified
- Not contain marketing spin ("almost", "nearly")

Example rewrites:
- "Aurel is autonomous." → "Aurel supports action-scoped autonomy evaluation with fail-closed decision rules."
- "Aurel is self-improving." → "Aurel has a roadmap path toward verified self-improvement through future skill promotion and evaluation gates."
- "Aurel is production-ready." → "Aurel is progressing toward Sovereign Agentic OS Seal validation."
- "Aurel has ABOS deployment." → "Aurel roadmap includes an ABOS Deployment Layer planned for P21.8."
- "Aurel has AETHER intelligence." → "Aurel roadmap includes an AETHER-style research and intelligence layer planned through P19."
