## Summary

Implemented the Tool Permission Policy Card Model — a closed-world, deterministic, hash-ready, deny-by-default policy card model defining tool categories, permission types, permission decisions, identity matchers, permission rules, and strict safety validation for credentials, shell commands, network egress, data residency compatibility, and dangerous permissions.

### Key Features
- Deny-by-default posture: default_decision must be deny
- Credential access: denied by default, cannot be allowed
- Shell command: requires sandbox/approval/risk constraints
- Network/external egress: governed, cannot be simple allow
- Execute/delete/config-write: require approval or explicit confirmation
- Data residency compatibility: protected classes cannot be exposed through external tools
- Broad allow-all matcher detection
- Dangerous metadata key rejection
- Default factory with 18 deny/guarded rules
- Deterministic canonical serialization and SHA-256 hashing
