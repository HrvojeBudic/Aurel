# P1.7.12 — Path/Source Conflict & Precedence Rules

**Roadmap:** AUREL Roadmap v5.1 — Integration-First
**Section:** P1.7 — Path Governance & Source Trust
**Status:** COMPLETE
**Successor:** P1.7.13 — Path Resolution Trace Hook

## 1. Purpose

P1.7.12 establishes deterministic, JSON-safe, hash-ready path/source conflict and precedence shadow objects. The model compares prior P1.7 path governance resolver, source trust resolver, risk, provenance, boundary, and authority context into non-enforcing conflict signals, precedence rules, and final shadow recommendations.

Conflict detection is not conflict enforcement. Precedence rule is not runtime authority. Strictest-wins recommendation is shadow-only.
