# P1.5.12 — Evaluation Case Extraction Seed

## Purpose

Create the first seed of Aurel's future evaluation/learning loop:

```
CapabilityEvidenceRecord
+ VerifierResult
+ TraceEventRef
+ EvidenceRef
+ ContextAdequacyReport
→ EvaluationCase / RegressionCandidate
```

P1.5.12 may create candidates. P1.5.12 may not accept, promote, remember, skill, reflex, or canonize anything automatically.

## What changed from P1.5.11B

P1.5.11B proved:
> verified capability depends on trace, source hash, evidence, verifier, limitations, evidence strength, and context adequacy

P1.5.12 proves:
> verified or failed outcomes can become future evaluation candidates without automatic promotion

## Extraction rules

### Positive EvaluationCase
- Requires: VERIFIED capability, PASS verifier, trace event ref, matching source hash, non-empty evidence refs, non-empty limitations
- Blocks: unsafe context, insufficient context
- Result: case_kind=positive, status=candidate

### RegressionCandidate
- Triggers on: FAILED capability, FAIL verifier, INSUFFICIENT/UNSAFE context, WEAK/NONE evidence, hash mismatch, missing evidence, missing limitations
- Result: RegressionCandidate(status=candidate)

### Review EvaluationCase
- Triggers on: NEEDS_REVIEW verifier, INCONCLUSIVE capability, PARTIAL context
- Result: case_kind=review, status=needs_review

## Failure modes

9 deterministic failure modes: verifier_failed, insufficient_context, unsafe_context, missing_evidence, weak_evidence, hash_mismatch, missing_limitations, policy_block, unknown.

## Seal criteria

P1.5.12 is sealed when Aurel can prove:

- A verified trace/context/evidence-bound capability result can become a candidate positive EvaluationCase
- A failed, unsafe, insufficient, weak, or unverifiable result can become a candidate RegressionCandidate
- Needs-review/inconclusive/partial-context results can become review cases
- No extracted case becomes accepted, promoted, remembered, skilled, or reflexed automatically

These states must be impossible:
- positive eval case without verified capability
- positive eval case without trace
- positive eval case with mismatched source hash
- positive eval case without evidence
- positive eval case with failed verifier
- positive eval case under unsafe context
- positive eval case under insufficient context
- accepted eval case by default
- skill/memory/reflex/capability creation during extraction
