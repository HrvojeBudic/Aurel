# P1.4.7 — Agent Identity Card Specification

**Phase:** P1.4.7  
**Status:** Implemented  
**Companion:** [P1.4 Scope Contract](P1.4_IDENTITY_AUTONOMY_SCOPE_CONTRACT.md), [P1.4 Agent Trust Constitution](P1.4_AGENT_TRUST_CONSTITUTION.md), [P1.4.6 Self-Model Spec](P1.4.6_SELF_MODEL_SPEC.md)

---

## 1. Purpose

The Agent Identity Card is Aurel's **machine-readable runtime identity card**. It binds stable agent identity to validated P1.4.1–P1.4.6 source hashes plus a local runtime instance id, distinguishes identity taxonomy (model/agent/workload/delegated/human), and exposes stable vs runtime hashes.

Identity proves who acts. It does not grant authority.

---

## 2. Non-goals

Not implemented: Delegation Mesh, Non-Repudiation Ledger, Workload Identity system, OAuth/OIDC/SPIFFE/SCIM, agent-to-agent protocol, Output Passport, Autonomy Scale, Measured Autonomy Score, Policy Cards, Path Governance, tool execution, external authentication, LLM calls, network access, secrets handling.

---

## 3. Agent Identity Card vs Identity Kernel

The kernel defines immutable trust boundaries. The card binds to the kernel hash but does not modify the kernel.

---

## 4. Agent Identity Card vs Persona Manifest

Persona defines expression behavior. The card identifies the agent; it is not voice or style.

---

## 5. Agent Identity Card vs Operator Contract

Operator Contract defines principal/delegate authority. The card reflects authority posture but cannot grant authority.

---

## 6. Agent Identity Card vs Self-Model

Self-Model is internal honest capability/limitation description. The card is the external machine-readable identity surface bound to self-model hash.

---

## 7. Identity taxonomy

- `agent_identity` must equal `agent.agent_id`
- `human_principal_identity` must be present and differ from `agent_identity`
- `model_identity`, `workload_identity`, `delegated_identity` may be null in P1.4.7
- Null placeholders surface "not implemented in P1.4.7" notes

---

## 8. Config and validation

Config validator enforces `applies_to_agent`, `card_class`, agent/authority/runtime/taxonomy exact values, all boundaries false, and AIC-001–AIC-006 invariant integrity (including string `expected_value` for AIC-006 `agent_type`).

Final-card validator additionally requires all six source-binding hashes (64 hex) and non-empty `runtime_instance_id`.

---

## 9. Stable vs runtime hash

- **Stable hash:** agent identity, authority, source bindings, taxonomy, boundaries, invariants, notes. Excludes `runtime_instance_id`, `runtime_started_at`, attestation.
- **Runtime hash:** stable material plus `runtime_instance_id`, `runtime_version`, `runtime_machine_scope`, `local_first`.
- Changing `runtime_instance_id` changes only the runtime hash.
- Changing any source hash changes both hashes.

---

## 10. Runtime instance id

Format: `aurel-runtime-<uuid4>`. Generated when not supplied. Non-secret, non-credential. `runtime_started_at` defaults to `None` and is excluded from hashes.

---

## 11. CLI usage

```bash
python -m agentic_runtime.cli identity card show --json
python -m agentic_runtime.cli identity card validate
python -m agentic_runtime.cli identity card hash
python -m agentic_runtime.cli identity card attest --json
python -m agentic_runtime.cli identity card taxonomy --json
```

Optional path overrides and `--runtime-instance-id` for deterministic tests.

---

## 12. Attestation behavior

`build_agent_identity_card_attestation()` / `write_agent_identity_card_attestation()` — explicit write only via CLI `--write` or tests.

---

## 13. Source bindings

Six hashes: identity kernel, persona manifest, operator contract, communication modes, identity prompt compiler policy, self-model.

---

## 14. Boundaries

All seven card boundaries must remain false: cannot grant authority, change kernel, change autonomy, create delegation, authorize tools, replace operator, override policy.

---

## 15. Invariants

AIC-001 through AIC-006 are critical, immutable, and use `fail_build`.

---

## 16. Builder behavior

`build_agent_identity_card()` validates config and all six sources, computes source hashes, assigns runtime instance id, computes stable and runtime hashes, validates final card.

`build_agent_identity_card_from_paths()` loads canonical configs, builds P1.4.6 self-model (FOCUS prompt context by default), then builds the card.
