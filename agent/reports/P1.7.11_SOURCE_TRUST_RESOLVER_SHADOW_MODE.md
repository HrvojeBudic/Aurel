**Roadmap:** AUREL Roadmap v5.1 — Integration-First

**Status:** COMPLETE
**Successor:** P1.7.12 — Path/Source Conflict & Precedence Rules

## 1. Purpose

P1.7.11 establishes deterministic, JSON-safe, hash-ready Source Trust Resolver v0 shadow objects. The resolver combines prior P1.7 source identity, source trust label/taxonomy, untrusted boundary, provenance/evidence, risk classification, and path governance resolver context into non-mutating `WOULD_*` trust recommendations.

Source Trust Resolver v0 is shadow-only. Trust recommendation is not trust mutation. `WOULD_TRUST` is not `TRUSTED`. `WOULD_DISTRUST` is not source blocking. `WOULD_QUARANTINE` is not quarantine action.
