## 1. Summary

P1.4.8 implements Aurel's first **action-scoped autonomy decision engine**. For any requested action, it determines:
- whether the action is allowed,
- which autonomy level A0–A7 applies,
- whether human approval is required,
- what evidence supports the decision,
- and what blocks the action if denied.

The engine is pure decision logic — it **does not** execute tools, compute global autonomy scores, or implement P1.4.9 Measured Autonomy Score.

## 7. Decision logic

```text
1. Validate request shape (structural validation)
2. Validate closed-world enums
3. Confirm agent identity card and operator contract exist
4. Baseline autonomy from action category
5. Lifecycle check (SUSPENDED/RETIRED → A7; ceiling enforcement)
6. Authority scope check (beyond SUGGEST → operator contract gating)
7. Capability evidence check (planned/roadmap → deny)
8. Risk escalation (R3→approval, R4→approval+escalation)
9. Reversibility escalation (R4–R5→approval, R6→denied)
10. High-risk/external-effect gate → human approval
11. Build AutonomyDecision
```

---

## 8. Fail-closed behavior

- Unknown action category → A7_DENIED
- Missing risk tier → A7_DENIED
- Missing reversibility tier → A7_DENIED
- R6_FORBIDDEN reversibility → A7_DENIED
- SUSPENDED agent → A7_DENIED
- RETIRED agent → A7_DENIED
- Critical risk without escalation path → A7_DENIED
- Planned roadmap capability → A7_DENIED
- Malformed request → `AutonomyValidationError`

## 13. Known limitations

1. Authority scope check is lenient when `execution_authority.allow_any` is absent — operators should configure this field for strict gating.
2. Lifecycle state is extracted via `getattr` probing; agents without a `lifecycle_state` field default to full access.
3. Tool manifest catalog integration is deferred — `tool_manifest_catalog` field in context is `None` (for P6 integration).
4. Policy context integration is deferred (for P1.5/P6 integration).

## 14. P1.4.9 handoff

P1.4.8 delivers the **decision engine**. P1.4.9 builds on it with:
- Measured autonomy score computation from historical decisions
- Trust decay over time
- Evidence-weighted autonomy scaling
- Aggregated agent autonomy profile

P1.4.8 explicitly does **not** compute any of these. The `AutonomyDecision` dataclass and `resolve_autonomy_decision()` are ready to be called by P1.4.9's measurement layer.
