### What P1.3 built (P1.3.0–P1.3.8)

- Domain models, validation, loader, manifest catalog registry, quarantine, invocation drafts, lifecycle events, research metadata, built-in JSON manifests (7 tools / 6 files)

## P1.3.8 — Built-in Seed Tool Manifests

**Module:** `src/agentic_runtime/tool_manifest/builtin_manifests.py`, `src/agentic_runtime/tool_manifest/manifests/*.json`

**Purpose:** Ship real local JSON manifest files for safe built-in Aurel tool capabilities and prove the P1.3 lifecycle (load → validate → quarantine → registry → invocation draft → lifecycle event) works as an integrated backend without execution power.

**Does not:** execute tools, register Tool Bus handlers, write files, run tests, call models, write memory, or grant authority.

**Key functions:** `get_builtin_manifest_directory()`, `load_builtin_tool_manifests()`

**Shipped tools (7):** `builtin.repo_scan`, `builtin.read_project_file`, `builtin.write_file_draft`, `builtin.run_tests_draft`, `builtin.create_evidence_record`, `builtin.create_memory_candidate`, `builtin.model_complete_structured`

**Integration path:**

```
manifests/*.json → load_builtin_tool_manifests → register_manifest_result → create_tool_invocation_draft → build_*_event
```

**Law:** Built-in manifest is declaration, not implementation. Registry visibility is not execution right. Invocation draft is not execution.

**Tests:** `tests/test_builtin_tool_manifests_p138.py` (23 tests)

**Note:** Manifests live under `tool_manifest/manifests/` (not `tools/manifests/`) because `tools.py` is the Tool Bus module.

## P1.3.6 — Tool Lifecycle Trace Events

**Module:** `src/agentic_runtime/tool_manifest/events.py`

**Purpose:** Serializable lifecycle events for manifest load, registry, quarantine, and invocation-draft transitions. In-memory recorder with composable builder functions.

**Does not:** execute tools, implement approval workflow, persist to database, or integrate with the P0.6 hash-chain ledger automatically.

**Key types:** `ToolLifecycleEventType`, `ToolLifecycleEvent`, `ToolLifecycleEventRecorder`

**Key builders:** `build_manifest_loaded_event`, `build_manifest_rejected_event`, `build_tool_registered_event`, `build_tool_rejected_event`, `build_tool_disabled_event`, `build_tool_enabled_event`, `build_quarantine_record_created_event`, `build_invocation_draft_event`, `build_registry_built_event`

**Integration path (composable, opt-in):**

```
load → build_manifest_*_event → recorder.record
register → build_tool_*_event → recorder.record
quarantine → build_quarantine_record_created_event → recorder.record
draft → build_invocation_draft_event → recorder.record
```

**Law:** Trace event is not execution and not verified evidence. Events do not grant authority.

**Tests:** `tests/test_tool_lifecycle_events_p136.py` (26 tests)
