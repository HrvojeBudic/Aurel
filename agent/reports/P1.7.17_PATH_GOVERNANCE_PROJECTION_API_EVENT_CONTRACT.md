**Status:** COMPLETE

## 1. Purpose

P1.7.17 establishes a deterministic, JSON-safe, hash-ready Path Governance Projection/API/Event Contract that exposes P1.7.0–P1.7.17 backend capability state through typed read-model and event-contract objects for future CLI/TUI/Shell/API surfaces.

Projection contract exposes state. It does not execute state.
API/event contract is not CLI binding. Read model is not source of truth.
