**Status:** COMPLETE
**Successor:** P1.7.11 — Source Trust Resolver v0 / Shadow Mode

## 1. Purpose

P1.7.10 establishes deterministic, JSON-safe, hash-ready Path Governance Resolver v0 shadow objects. The resolver combines prior P1.7 path identity, source identity, trusted root, boundary, authority, untrusted boundary, provenance, and risk context into non-enforcing `WOULD_*` recommendations.

Resolver v0 is shadow-only. Shadow decision is not enforcement. Recommended action is not runtime action. `WOULD_DENY` is not `DENY`. `WOULD_ALLOW` is not `ALLOW`.
