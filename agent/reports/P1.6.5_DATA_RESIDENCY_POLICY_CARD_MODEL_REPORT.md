## Summary

Implemented the Data Residency Policy Card Model — a closed-world, deterministic, hash-ready policy card model defining data residency zones, data classes, processing locations, egress/exposure/redaction/storage rules, and strict local-first defaults.

## Implemented Components

### Enums (6)
- `DataResidencyZone` — 7 values: local_only, local_private, eu_only, trusted_region, external_allowed, public, forbidden
- `DataClass` — 20 values: public, internal, confidential, secret, operator_private, personal_data, sensitive_personal_data, business_confidential, financial, credentials, source_code, memory_record, trace_record, evaluation_record, model_prompt, tool_output, artifact, system_config, policy_record, identity_record
- `ProcessingLocation` — 7 values: local_device, local_network, eu_region, trusted_region, external_api, public_web, forbidden
- `RedactionRequirementType` — 9 values
- `StorageRequirementType` — 6 values
- `DataExposurePermission` — 8 values

### Dataclasses (8)
- `RedactionRequirement`, `StorageRequirement`, `DataEgressRule`, `DataExposureRule`, `DataResidencyRule`
- `DataResidencyPolicyCard` (container pattern: contains `PolicyCard` + typed fields)
- `DataResidencyValidationIssue`, `DataResidencyValidationResult`

### Key Features
- Strict local-only safety: zero outbound (no egress, no external model, no external API, no web search)
- Credentials safety: no-egress, encryption required, audit trace required
- sensitive_personal_data/memory_record/trace_record: forced local-only, no-egress
- Forbidden zone: non-permissive (no external model/api/web allowed)
- Closed-world validation with dangerous field/key rejection
- Default factory: 20 data class rules, all local-only except public
- Deterministic canonical serialization and SHA-256 hashing
