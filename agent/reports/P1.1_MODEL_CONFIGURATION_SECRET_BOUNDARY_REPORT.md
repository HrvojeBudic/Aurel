# P1.1 — Model Configuration + Secret Boundary Report

**Date:** 2026-06-17  
**Status:** PASS (local verification)

## 1. Summary

P1.1 centralizes model/provider configuration under `agent/config/` and introduces an explicit secret boundary. Providers and model profiles are declared in YAML (no raw secrets). Secrets resolve from environment variables only. `SecretRedactor` scrubs obvious secret patterns from errors, status, and reports. `ModelRouter` accepts an optional `ModelConfigBundle`, respects `local_only`, and remains backward-compatible with existing mock/offline tests. CLI adds `config validate`, `models list`, and `providers status`.

## 4. Model profile architecture

Each profile in `models.yaml` defines:

- `provider` — reference to a provider in `providers.yaml`
- `model` — model identifier passed to the provider adapter
- `purpose` — human/operator label (planning, coding, review, etc.)
- `allowed_tasks` — task tags for `ModelRouter.select_profile_for_task()`

Default profiles use `mock` so offline tests require no API keys.

## 5. Provider profile architecture

Each provider in `providers.yaml` defines:

- `type` — `mock`, `ollama`, `openai`, or `anthropic`
- `residency` — `local` or `remote`
- `api_key_env` — env var name only (remote providers)
- `base_url_env` / `default_base_url` — endpoint configuration
- `default_model_env` / `default_model` — model selection

Raw `api_key` fields in YAML are rejected at load time.

## 6. Secret boundary rules

1. Secrets resolve from environment variables via `EnvSecretProvider` only.
2. Missing secrets return structured `SecretResolutionResult` (no crash unless a remote call requires the key).
3. `assert_no_raw_secrets_in_yaml()` rejects `api_key`, `secret`, `token`, etc. in config files.
4. `SecretRedactor` redacts: env-key patterns, `sk-*` tokens, Bearer tokens, high-entropy strings.
5. `local_only: true` disables remote providers at validation and runtime.
6. `require_secret_redaction: true` (default) — provider errors and health messages pass through redactor.

## 10. Known limitations

- YAML parser is a constrained subset (not full YAML 1.1); complex anchors/aliases unsupported.
- Remote provider profiles cannot be loaded when `local_only: true` — by design.
- `ModelRouter` without `config` behaves as P0.12 (env `AUREL_MODEL_PROVIDER` only).
- Ollama healthcheck remains conservative (does not probe local daemon unless used).
- No prompt registry, patch synthesis, integrations, MCP, or desktop UI in this phase.
