## 1. Purpose

P1.7.5 establishes deterministic, string-level path normalization and shadow escape candidate detection. It produces JSON-safe, hash-ready result objects, preserves source-label truth, and explicitly avoids resolver, authority, sandbox, filesystem, CLI, trace, Ledger, or enforcement behavior.

Core law: normalization means represent, not resolve. Escape detection means classify candidates, not deny or block.

## 3. Implemented

- `normalize_path_for_governance()`

- Raw path preservation with separate deterministic `normalized_path` and `display_path`

- Closed-world validation; unknown fields reject with `UNKNOWN_FIELD`
- Focused tests for exports, normalization, boundary classification, hash determinism, signal detection, non-enforcement, and no filesystem access

## 5. Integration-First Truth

- Backend normalization and escape detection contract exists and is importable from `agentic_runtime.path_governance`.
- `PATH_OK` means no candidate mismatch under supplied string context only; it does not mean safe or authorized.
- `PATH_OUTSIDE_TRUSTED_ROOT` and `PATH_TRAVERSAL_CANDIDATE` are candidate classifications only, never runtime denial or block.
- Test and fixture objects use `DEV_FIXTURE`; production helper defaults remain `LIVE`.
- Projection/API/event contract remains **UNAVAILABLE** until P1.7.17.
- CLI/TUI binding remains **UNAVAILABLE** until P1.7.18.
- Full path authority scope model remains **UNAVAILABLE** until P1.7.6.

## 6. Boundary Summary

- Normalization does not resolve paths on disk.
- Escape detection does not enforce sandbox or runtime policy.
- Traversal-like `..` segments are preserved and signaled; they are not blocked.
- Absolute paths without root context return `PATH_UNRESOLVED`, not deny/block.
- Registry roots are sorted deterministically by `root_id` for matching and mismatch context.

## 7. Governance Boundary

P1.7.5 creates the Path Normalization & Escape Detection Contract; it does not add trusted root authority resolution, path/source resolver behavior, path permission enforcement, filesystem security, runtime enforcement, Ledger writes, approval activation, CLI/TUI binding, Shell UI, filesystem reads, symlink resolution, or sandbox behavior changes.

Additional boundary confirmations:

- No `AgenticRuntime.submit` call or import.
- No runtime, sandbox, approval, policy, tools, trace, CLI, or CLI module changes.
- No file reads, path existence checks, permission checks, stat calls, symlink resolution, or live filesystem state in hashes.
