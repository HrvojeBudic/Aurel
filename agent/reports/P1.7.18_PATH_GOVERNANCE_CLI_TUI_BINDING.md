# P1.7.18 — Path Governance CLI/TUI Binding

**Roadmap:** AUREL Roadmap v5.1 — Integration-First

**Status:** COMPLETE
**Successor:** P1.7.19 — Docs/State/Reports Update

## 1. Purpose

P1.7.18 establishes a deterministic, JSON-safe, read-only Path Governance CLI/TUI binding that renders P1.7.17 projection/read-model/API envelope state to operator-facing terminal output without creating runtime authority, policy decisions, approval activation, Ledger writes, global trace emission, source mutation, prompt filtering, memory/tool gating, or sandbox/runtime changes.

Path Governance CLI/TUI Binding exposes projection state to the operator. It does not create authority. It does not execute policy. It does not mutate path/source governance state.

## 4. Command Coverage

- `STATUS` — overall projection state, capability counts, source labels
- `CAPABILITIES` — capability records with state labels and unavailable reasons
- `READ_MODEL` — JSON-safe read model payload
- `API_ENVELOPE` — JSON-safe API envelope with contract name/version
- `EVENTS` — projection event contract objects (not global trace)
- `HARNESS_SUMMARY` — path governance harness projection summary
- `POLICY_CONTEXT_SUMMARY` — policy context bridge summary (`policy_called=false`)
- `TRACE_HOOK_SUMMARY` — path resolution trace hook projection summary
- `VIOLATION_DRIFT_SUMMARY` — violation/drift trace hook projection summary
- `UNAVAILABLE_BINDINGS` — Shell/HTTP/policy/Ledger/enforcement unavailable reasons

## 5. Output Coverage

- `TEXT` — human-readable status and summary output
- `JSON` — JSON-safe payload via `json_payload`
- `TABLE` — deterministic capability table rows
- `TUI_TEXT` — terminal-readable boxed plain text (not interactive TUI framework)
- Source labels preserved on response and rendered lines
- Unavailable reasons preserved in response and UNAVAILABLE command output
