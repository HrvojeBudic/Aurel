## 1. Summary

P1.4.4 implements Aurel's **validated cognitive/output mode registry**. The Communication Modes registry loads from `config/aurel/communication_modes.yaml` into frozen typed dataclasses, validates all global boundaries, per-mode authority prohibitions, HERETIC-specific candidate-only rules, and the CM-001–CM-008 invariant registry, computes a deterministic SHA-256 hash, provides case-insensitive mode lookup, builds prompt-safe per-mode summaries, and exposes CLI commands.

Modes shape reasoning and output. They cannot grant permissions, change autonomy, override identity/persona/operator/policy, write memory, canonize output, or execute actions.

Canonical registry hash: `df8b6aeb58f4d1492b92d17cab4f7bf83c5ebb90138f1517dd5dcf89b3b7bdb1`

## 3. Mode registry schema summary

Top-level: `schema_version`, `registry_name`, `registry_class: mode_expression_registry`, `applies_to_agent: Aurel`.

Sections: `global_boundaries` (10 false booleans), `modes` (7 required modes), `invariants` (CM-001..008), `notes`.

Each mode: `purpose`, `cognitive_posture`, `output_bias`, `challenge_emphasis`, `risk_emphasis`, `boundaries` (bool maps).

Typed objects: `AurelCommunicationModeRegistry`, `CommunicationModeGlobalBoundaries`, `CommunicationModeSpec`, `CommunicationModeInvariant`, `CommunicationModeRegistryHash`, `CommunicationModeValidationResult`, `CommunicationModeAttestation`, `CommunicationModeSafeSummary`, `CommunicationModeLookupResult`.

## 4. Required mode list

FOCUS, DEBUG, DEPLOY, SHADOW, EVOLVE, CHANNEL, HERETIC — all present and validated. Mode names stored canonical UPPERCASE.

## 5. Global boundaries

All ten `global_boundaries.*` fields must be false: no permission grants, autonomy changes, identity/persona/operator/policy overrides, constitutional floor disable, direct memory writes, output canonization, or action execution.

## 6. Heretic boundary summary

HERETIC enforces `output_bias.candidate_only: true` and additional boundaries: `writes_files`, `modifies_policy`, `modifies_identity`, `modifies_memory`, `modifies_tools`, `modifies_autonomy`, `real_world_side_effects` all false. Cognitive freedom only — not uncontrolled execution. Full Heretic Sandbox is P1.4.16.

## 8. Validation rules implemented

- Identity: `applies_to_agent == Aurel`, `registry_class == mode_expression_registry`
- Global boundaries: all 10 false
- Required modes: all 7 present
- Per mode: non-empty purpose/posture; standard boundaries false
- HERETIC: candidate_only true; extended boundaries false
- Invariants: structure, unknown key fail, expected_value match, critical immutable + fail_boot

## 9. Hashing behavior

`registry_to_canonical_dict()` produces sorted primitive dict (modes and invariants sorted); `json.dumps(sort_keys=True, separators=(",", ":"))`; SHA-256. Verified deterministic, YAML-order-invariant, and sensitive to critical boundary changes.

---

## 10. Mode lookup behavior

`get_communication_mode(registry, mode_name)` returns `CommunicationModeLookupResult`. Case-insensitive lookup normalizes to canonical UPPERCASE. Unknown modes return `found: false` with error message. No session state, no authority, no execution.

---

## 11. Safe summary behavior

`build_communication_mode_safe_summary(registry, mode_name)` returns per-mode summary with purpose, cognitive posture, output/challenge/risk rules, and authority boundaries. HERETIC summary includes explicit candidate-only and no-side-effect fields in JSON output. Deterministic. No raw YAML, no tool/autonomy/execution permission language. Preparation object for P1.4.5 — not the compiler.

## 12. CLI commands

CLI uses the `identity` namespace:


Optional `--modes-path`. Attestation writes only with explicit `--write`.

## 15. Known limitations

- Registry is not wired into runtime boot or prompt rendering — load/validate/hash/lookup/summary only
- Safe summary is a preparation object; actual prompt compilation is P1.4.5
- Attestation file requires explicit `--write`; no silent writes on import
- No active mode session state — lookup only
- HERETIC boundaries are registry-level; full Heretic Sandbox engine is P1.4.16
- No enforcement linkage to policy/runtime execution (intentional — modes are not authority)
