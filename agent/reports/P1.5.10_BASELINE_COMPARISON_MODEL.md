## 5. Baseline reference model

`BaselineReference` captures kind, status, and referential links (results, evidence, bindings, hygiene, adversarial cases). ACTIVE baselines require refs; INVALID/BLOCKED require blockers; STALE requires warnings.

## 6. Comparison dimensions

Core: outcome, verdict, confidence, evidence quality, failure modes, support/conflict levels, hygiene, contamination risk, adversarial/negative-control coverage.

Sparse: sparse context quality, evidence recall, lost context risk, multi-hop trace integrity, contradiction survival, context budget efficiency, governed context selection, authority-aware retrieval.

## 7. Comparison signals and confidence semantics

Signals: `IMPROVED`, `DEGRADED`, `UNCHANGED`, `MIXED`, `INCONCLUSIVE`, `INCOMPARABLE`, `BLOCKED`.

Confidence: `LOW`, `MODERATE`, `HIGH`, `INSUFFICIENT`, `UNKNOWN` — categorical only.

## 8. Default comparison policy

Safe defaults: same-kind required, active baseline for high confidence, block invalid/blocked baselines, downgrade stale confidence, require hygiene and adversarial coverage for improvement claims, `allow_numeric_scores=False`.

## 9. Baseline reference validation rules

Empty id, UNKNOWN kind as ACTIVE, ACTIVE without refs, INVALID/BLOCKED without blockers, STALE without warning, numeric score claims rejected.

## 10. Comparison input validation rules

Empty comparison id, invalid refs, blocked refs, empty/UNKNOWN dimensions, kind mismatch, numeric score usage when disallowed.

## 11. Evaluation result comparison rules

Ordinal categorical mapping for outcome/verdict/confidence/evidence quality; inverted scoring for failure modes (fewer failures = improved). Critical dimension degradation prevents blind IMPROVED. Hygiene/adversarial guards downgrade improvement to MIXED when coverage regresses.

## 12. Adversarial coverage comparison rules

More refs → IMPROVED; missing baseline refs → DEGRADED; same non-empty → UNCHANGED; both empty → INCONCLUSIVE. No case execution.

## 13. Hygiene reference comparison rules

Current has refs when baseline lacks → IMPROVED; missing current refs → DEGRADED; same refs → UNCHANGED. Does not reassess hygiene.

## 14. Sparse Cognition baseline comparison readiness

Eight sparse dimensions supported via enum and failure-mode proxy comparison. ASCL engine, Sparse Context Compiler, retrieval router, evidence graph builder, SSA not implemented.
