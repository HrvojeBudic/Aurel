# P1.4.7-MG — Agent Identity Card Merge Gate Hardening Report

_Date: 2026-06-21_

## 1. Summary

P1.4.7-MG is a merge-gate hardening patch applied after P1.4.7 Agent Identity Card and before P1.4.8 Autonomy Scale Engine. It fixes two contract bugs (ignored `self_model_policy_path` at final card validation; under-reported P1.4.7 capability inventory), introduces `IdentitySourceBundle` for single-load identity sources, begins CLI decomposition, aligns CLI default config resolution with the library, removes debug artifacts, and eliminates duplicate card construction wiring.

**Merge approval status:** Approved for P1.4.8 entry — identity/card stack is honest, path-respecting, and test-backed. Three pre-existing tool-bus issuer tests remain unrelated to this patch (see §6).

## 2. Bugs fixed

| Bug | Fix |
|-----|-----|
| `build_agent_identity_card` silently reloaded default self-model policy | `self_model_policy` is now a required parameter; `build_agent_identity_card_with_default_policy()` wrapper loads default explicitly |
| `--self-model-policy-path` ignored at final card validation gate | `build_agent_identity_card_from_paths` loads policy once via `IdentitySourceBundle` and threads the same object through self-model build and card validation |
| Self-model inventory marked Agent Identity Card as `planned` | Canonical inventory in `identity/capability_inventory.py` marks `agent_identity_card` as `implemented` / `P1.4.7`; validation registries derive from this source |
| CLI default config dir diverged from library | `cli_modules/common.config_dir()` uses `model_config.default_config_dir()` |
| Debug log in repo | Removed `.cursor/debug-541252.log`; added `.cursor/debug-*.log` to `.gitignore` |

## 3. Structural refactors completed

- **`IdentitySourceBundle`** (`identity/source_bundle.py`): loads identity kernel, persona, operator contract, modes, compiler policy, self-model policy, and card config once; tracks resolved paths, raw file SHA-256, and canonical object hashes; provides `build_aurel_self_model_from_bundle()` and validation helper.
- **`capability_inventory.py`**: single source of truth for self-model capability status; `PLANNED_CAPABILITY_IDS` / `IMPLEMENTED_CAPABILITY_IDS` imported by validation.
- **CLI decomposition**: identity command handlers (~1430 lines) extracted to `cli_modules/identity_commands.py`; shared helpers in `cli_modules/common.py`. `cli.py` reduced from ~2411 to ~1013 lines (composition root retained).
- **Card construction**: duplicate 40-line field wiring replaced with `dataclasses.replace()` for hash fields.

## 4. Structural debt deferred

### 4.1 Identity stack copy-paste

Recommend consolidating repeated load/validate/hash/attest patterns into shared modules before P1.4.8+:

```
identity/artifacts.py
identity/validation.py
identity/hashing.py
identity/attestation.py
identity/sources.py
```

Shared helpers (domain validation must remain strict):

- `validate_closed_world_mapping(...)`
- `canonical_hash(...)` / `raw_source_hash(...)`
- `build_attestation(...)`
- `validate_allowed_enum(...)` / `validate_required_fields(...)`

### 4.2 `tool_manifest/validation.py` monolith (~1051 lines)

Plan split by concern before P6/P7 bridging:

```
tool_manifest/validation/schema.py
tool_manifest/validation/contracts.py
tool_manifest/validation/permissions.py
tool_manifest/validation/invocation.py
tool_manifest/validation/errors.py
```

### 4.3 Two `ToolRegistry` classes

- `tools.py`: execution registry (runtime tool dispatch)
- `tool_manifest/registry.py`: manifest catalog/registry

Recommend rename before P6/P7: `ExecutionToolRegistry` and `ManifestToolCatalog`. Too invasive for this patch; documented as mandatory pre-P6/P7 refactor.

### 4.4 Remaining CLI decomposition

Non-identity commands (config, models, prompts, repo-task, harness) remain in `cli.py`. Target further extraction in a follow-up patch.

### 4.5 Callers still using path-based reload

`build_aurel_self_model_from_paths` and prompt-context CLI paths reload sources independently. Bundle covers the P1.4.7 card path; full-stack bundle adoption deferred.
