## 1. Purpose

P1.7.7 establishes deterministic, JSON-safe, hash-ready untrusted content boundary declaration objects. It models how content may influence Aurel later through typed influence surfaces and future-governance restrictions without active prompt filtering, prompt rewriting, memory write gating, tool argument blocking, resolver behavior, or runtime enforcement.

Core law: untrusted content may inform, but must never command. Content boundary model is not active firewall.

- `UntrustedContentKind`: EXTERNAL_TEXT, UPLOADED_FILE_CONTENT, WEB_CONTENT, TOOL_OUTPUT, MODEL_OUTPUT, AGENT_OUTPUT, MEMORY_RECALL, PATH_REFERENCED_CONTENT, UNKNOWN

- `BoundaryRestriction` with deterministic `restriction_id`
- `UntrustedContentBoundary` with `SourceIdentity`, `SourceTrustLabel`, influence surfaces, restrictions, deterministic `boundary_id` and `boundary_hash`
- `UntrustedContentBoundaryRegistry` with order-insensitive deterministic `registry_hash`
- `build_untrusted_content_boundary()`

- Closed-world validation; unknown fields reject with `UNKNOWN_FIELD`

## 6. Information vs Instruction Boundary Summary

- Untrusted content may inform.
- Untrusted content must never command.
- Content boundary model is not active firewall.
- Boundary restriction is not enforcement.
- Prompt instruction restriction does not rewrite prompts.
- Tool argument restriction does not block tools.
- Memory write restriction does not write or block memory.
- Authority expansion restriction does not call resolver.
- Quarantined means restricted, not deleted.
- Trusted marker does not grant command authority.

## 7. Governance Boundary

P1.7.7 creates the Untrusted Content Boundary Model; it does not add source provenance/evidence binding, path/source risk classification, path/source resolver behavior, source trust resolver behavior, active prompt filtering, prompt rewriting, memory write gating, tool argument blocking, authority resolution, filesystem security, network access, runtime enforcement, Ledger writes, approval activation, CLI/TUI binding, Shell UI, or sandbox behavior changes.
