## 5. Evaluation Mirror foundation model

```
EvaluationDomain → EvaluationScope (with non_goals)
EvaluationSubjectType → EvaluationSubject (evidence_refs)
EvaluationCriterion (required, evidence_required)
→ EvaluationRunEnvelope (auditable run prep — does NOT verify)
```

## 6. P1.5 vs P4 distinction

| P1.5 | P4 |
|------|-----|
| Foundation: domains, subjects, scopes, criteria, envelopes | Full mirror across Core, Hubs, model lanes, memory, artifacts |
| Prepares auditable evaluation runs | Runs benchmarks, scores, promotes capabilities |
| No scoring hype | Comprehensive evaluation pipeline |
