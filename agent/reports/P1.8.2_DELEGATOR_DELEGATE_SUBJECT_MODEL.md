# P1.8.2 — Delegator / Delegate / Subject Model

**Task ID:** P1.8.2
**Date:** 2026-06-26
**Roadmap:** Aurel Roadmap v5.1 — Integration-First
**Parent section:** P1.8 — Delegation / Non-Repudiation / Agent Identity Mesh
**Status:** COMPLETE

## Purpose

Create a deterministic, versioned, JSON-safe, side-effect-free role model for the delegation triangle (delegator → delegate → subject) bound to P1.8.1 `DelegationRef` / `DelegationIdentity` without approving, executing, enforcing, verifying, activating, or granting authority.

## Scope

### Implemented

- `DelegationRoleKind` enum: DELEGATOR, DELEGATE, SUBJECT, OBSERVER, UNKNOWN
- `DelegationRoleBindingStatus` enum: ROLE_BOUND, REFERENCE_ONLY, UNAVAILABLE, ERROR, UNKNOWN
- `DelegationPartyRoleRef` frozen dataclass: role-bound wrapper around actor reference for delegator/delegate
- `DelegatedSubjectRef` frozen dataclass: role-bound wrapper around delegated subject data/ref
- `DelegationRoleBinding` frozen dataclass: one delegation identity-to-role binding
- `DelegationRoleBindingSet` frozen dataclass: full delegator → delegate → subject triangle
- `DelegationRoleSideEffects` frozen dataclass: 11 all-false booleans
- `DelegationRoleStatusReport` frozen dataclass: role model readiness report
- Deterministic hash functions: `compute_role_ref_hash`, `compute_subject_role_hash`, `compute_role_binding_hash`, `compute_role_binding_set_hash`, `compute_role_status_report_hash`
- Builder functions: `build_delegation_party_role_ref`, `build_delegated_subject_ref`, `build_delegation_role_binding`, `build_delegation_role_binding_set`, `build_delegation_role_status_report`
- Serialization: `serialize_delegation_role_binding_set`, `hash_delegation_role_binding_set`
- Closed-world field validation
- Versioned schemas
- `src/agentic_runtime/delegation/__init__.py` exports all P1.8.2 symbols
- 34 focused tests in `tests/delegation/test_p1_8_2_roles.py`

## Side-effect proof

All 11 `DelegationRoleSideEffects` booleans default to `false` and are verified false in tests. No policy call, no Custos call, no approval creation, no Ledger write, no global trace write, no runtime mutation, no delegation execution, no delegation enforcement, no delegate activation, no subject execution, no authority verification.

## Explicit negatives

- DelegationPartyRoleRef identifies actor role; it does not verify authority.
- Delegate role ref exists ≠ delegate activated.
- DelegatedSubjectRef describes what is delegated; it does not execute task/action/output.
- DelegationRoleBinding binds role metadata; it is not approval.
- DelegationRoleBindingSet describes delegation triangle; it is not enforcement.
- Role binding is not permission grant.
- role_binding_hash exists ≠ TRACE_VERIFIED.
- Role model exists ≠ resolver exists.
- No policy/Custos/approval/Ledger/global trace/runtime mutation.
- No crypto signing or signature verification.
- No agent activation.
- No non-repudiation verification.
