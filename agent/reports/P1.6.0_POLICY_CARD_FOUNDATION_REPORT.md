- 8 known top-level fields

### Deterministic serialization

- `policy_card_to_canonical_dict()` — sorted-key primitive dict

### Hash readiness

- `compute_policy_card_hash()` — SHA-256 hex digest of canonical serialization

## Known limitations

1. **No resolver**: Policy cards exist as typed data objects but are not yet evaluable at runtime. The resolver (P1.6.12+) will consume these models.
2. **No schema generation**: JSON Schema or YAML schema for policy cards is not generated yet (P1.6.1).
3. **No YAML file loader**: Only `load_policy_card_from_dict()` is implemented. YAML file loading deferred to P1.6.1 or later.
4. **No registry**: No central registry of loaded policy cards exists yet.
5. **Hash is not signed**: `compute_policy_card_hash()` is a plain SHA-256 digest, not a cryptographic signature or attestation.
