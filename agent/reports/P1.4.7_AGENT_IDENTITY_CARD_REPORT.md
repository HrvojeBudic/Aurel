# P1.4.7 — Agent Identity Card v2.0 Report

**Date:** 2026-06-21  
**Status:** PASS

## 1. Summary

P1.4.7 implements Aurel's **machine-readable runtime identity card**. The Agent Identity Card loads config from `config/aurel/agent_identity_card.yaml`, validates P1.4.1–P1.4.6 identity sources, binds six source hashes, assigns a local runtime instance id, computes stable and runtime SHA-256 hashes, and exposes CLI commands under `identity card`.

Identity proves who acts. It does not grant authority, create delegation, authorize tools, or replace runtime governance.

Example stable agent identity hash (FOCUS context, fixed runtime id): `a1ee7d6f5d0b22660b8bf523fb3e5f2240929f8e40b90be6ef5068335737a2ba`  
Example runtime agent identity card hash: `a0ceaf5bb411a8701906135f96eafa7f34d5b7f76ceae54d9dc1ce1daa0b34f1`

## 3. Card config summary

- `card_class: machine_readable_agent_identity`
- Agent: `aurel.local.operator.primary`, type `ai_agent`, local-first deployment
- Authority: Operator final authority; no self-escalation; tool access does not imply authority
- Source bindings null in config; populated at build time
- Runtime strategy: `local_generated_uuid`; `runtime_started_at` null
- Taxonomy: agent vs human principal distinguished; model/workload/delegated null
- All seven boundaries false
- AIC-001–AIC-006 critical invariants with `fail_build`

---

## 4. Source bindings summary

Six hashes from P1.4.1–P1.4.6: identity kernel, persona manifest, operator contract, communication modes, identity prompt compiler policy, self-model.

---

## 5. Identity taxonomy summary

- `agent_identity` == `agent.agent_id`
- `human_principal_identity` == `operator.primary` (distinct from agent)
- `model_identity`, `workload_identity`, `delegated_identity` null with explicit P1.4.7 not-implemented notes

---

## 6. Runtime instance id summary

Format `aurel-runtime-<uuid4>`. Generated when not supplied. Non-secret, non-credential. Excluded from stable hash; included in runtime hash.

---

## 7. Stable vs runtime hash behavior

Stable hash excludes runtime instance fields. Runtime hash includes `runtime_instance_id`, `runtime_version`, `runtime_machine_scope`, `local_first`. Source hash changes affect both hashes.

---

## 8. Validation rules implemented

Config validator: applies_to_agent, card_class, agent/authority/runtime/taxonomy exact values, boundaries, invariant integrity (bool and string expected values).

Final-card validator: populated source hashes, runtime instance id, computed hash fields.

---

## 9. Builder behavior

Validates config + six sources, computes hashes, assigns runtime id, computes stable/runtime hashes, validates final card. `build_agent_identity_card_from_paths()` compiles FOCUS prompt context for self-model by default.

---

## 10. Attestation behavior

Attestation includes stable/runtime hashes, all source hashes, runtime instance id, validation status. Write is explicit only.

---

## 11. CLI surface

`identity card show|validate|hash|attest|taxonomy` with path overrides, `--runtime-instance-id`, `--json`, `--write` for attest.
