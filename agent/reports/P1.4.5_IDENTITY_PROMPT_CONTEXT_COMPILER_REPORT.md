**Date:** 2026-06-21

## 1. Summary

P1.4.5 implements Aurel's **first identity-aware prompt compilation layer**. The Identity Prompt Context Compiler loads compiler policy from `config/aurel/identity_prompt_compiler.yaml`, validates all four identity sources (Kernel, Persona, Operator Contract, Communication Modes) plus a selected mode, applies dominance rules, detects contradictions, builds an eight-section `IdentityPromptContext` from safe summaries (never raw YAML), computes a deterministic SHA-256 context hash, renders a deterministic prompt fragment, and exposes CLI commands under `identity context`.

Prompt context can guide the model. Runtime governance still enforces action.

Canonical compiler policy hash: `365971dc84a0a8302e0a1e48aa85a750b396743e4f4d5d092975aa15a9a608ed`  
Example FOCUS context hash: `1dbafd83d89a6c8aaa86e4f3755b858cdd6b149ffb912206a685cb653d70c811`

## 3. Compiler policy summary

- `compiler_class: safe_identity_context_compiler`
- All `source_requirements` mandatory flags true
- All 15 `safety` flags true (raw YAML forbidden, authority/honesty boundaries required)
- All 5 `dominance` flags true
- All 8 `prompt_sections` enabled
- IPC-001–IPC-008 critical invariants with `fail_compile`

---

## 4. Source dominance order

1. Identity Kernel  
2. Operator Relationship Contract  
3. Persona Manifest boundaries  
4. Communication Mode boundaries  
5. Selected mode output shaping  

Lower-layer contradictions fail compilation.

---

## 5. Compiled context schema

`IdentityPromptContext` includes agent metadata, `IdentityPromptSourceBundle` (five hashes), and eight section tuples. `IdentityPromptCompileResult` carries validity, contradictions, and optional context hash.

---

## 6. Prompt sections

`agent_identity`, `operator_relationship`, `persona_expression`, `active_mode`, `authority_boundaries`, `capability_honesty`, `non_goals`, `source_integrity`

HERETIC active_mode section adds candidate-only and no-modification lines.

---

## 7. Contradiction detection

28+ contradiction classes (CTR-001–CTR-028+) covering invalid sources, authority violations, mode violations, HERETIC boundaries, compiler policy violations, and post-build missing content. Critical contradictions nullify context output.

---

## 8. Context validation

Section-specific checks for Operator final authority, no-self-escalation, capability honesty, authority boundary statements, source hashes, and HERETIC-specific content.

---

## 9. Hashing behavior

Deterministic SHA-256 over canonical JSON (`sort_keys=True`, compact separators). Mode or any source hash change alters context hash.

---

## 10. Renderer behavior

`render_identity_prompt_context()` produces ordered `## section` headers with bullet lines. No raw YAML, no secrets, no side effects.

---

## 11. Attestation behavior

`build_identity_prompt_attestation()` binds context hash to five source hashes. `write_identity_prompt_attestation()` writes JSON only on explicit CLI `--write` or test invocation.

---

## 12. CLI commands

```bash
python -m agentic_runtime.cli identity context compile --mode DEPLOY --json
python -m agentic_runtime.cli identity context validate --mode FOCUS
python -m agentic_runtime.cli identity context hash --mode SHADOW
python -m agentic_runtime.cli identity context render --mode DEPLOY
python -m agentic_runtime.cli identity context attest --mode HERETIC --json
```

`--mode` is required for all subcommands.
