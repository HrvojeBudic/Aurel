## 1. Purpose

P1.7.8 establishes deterministic, JSON-safe, hash-ready source provenance and evidence binding reference objects. It connects source identity, provenance lineage seed, evidence declarations, claim references, boundary state, authority context, and path/source context without truth verification, trace event emission, Ledger writes, resolver behavior, or runtime enforcement.

Core laws:

- Provenance binding is not truth verification.
- Evidence reference is not Ledger write.
- Claim binding is not claim acceptance.
- Source evidence is not resolver decision.
