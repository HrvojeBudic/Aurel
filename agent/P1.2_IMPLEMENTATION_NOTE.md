# P1.2 Implementation Note — Prompt System Seed

## 1. Current hardcoded prompts

- `src/agentic_runtime/repo_agent.py`: `LLMRepoPlanner._build_prompt()` contains the repository planning system prompt and user prompt JSON assembly.
- `src/agentic_runtime/model_router.py`: `MockModelClient.complete()` and router calls pass prompt strings through to providers, but do not own prompt content.
- `src/agentic_runtime/model_providers/mock_provider.py`: the mock provider inspects `request.user_prompt` for deterministic test behavior, but does not define operator prompt policy.
- Tests pass literal `"system"` / `"GOAL: ..."` strings to model/router/provider seams.

## 2. Repo planning / routing / mock prompt usage

- Repo planning uses one governed system prompt plus one JSON user prompt for `REPO_PLAN_SCHEMA`.
- Model routing treats prompts as provider inputs and enforces provider/model availability, not prompt authority.
- Mock provider uses prompt text only to choose deterministic structured outputs for offline tests.

## 3. P1.1 model profile connection

- Prompt manifests should declare `allowed_model_profiles`.
- `PromptRegistry` can validate these names against `ModelConfigBundle.profiles` when a P1.1 config bundle is supplied.
- Loading without config remains valid so tests and offline usage do not require API keys or remote providers.

## 4. Prompt rendering location

- Rendering belongs in a new `src/agentic_runtime/prompt_system.py` module.
- `LLMRepoPlanner` may optionally render `repo_planner` through `PromptRegistry`, while keeping the existing hardcoded prompt fallback.

## 5. Prompt trace summary location

- `PromptRenderResult` should produce a trace-safe `PromptTraceSummary` at render time.
- P1.2 should not persist raw prompt text by default; later trace integration can append the summary object.

## 6. Secret redaction

- `SecretRedactor` from `src/agentic_runtime/secrets.py` must be applied to rendered previews, CLI output, errors, and summaries.
- Prompt manifests and rendered prompts must reject or redact obvious raw secret-like values such as `sk-*`, Bearer tokens, and env-key assignments.
