## What this alpha is

P1.0 Runtime Alpha is the first externally describable seal of the **governed agent runtime kernel**:

- A stdlib-only Python runtime where entities propose and the runtime disposes
- Full command pipeline: policy → HITL/approval → budget → sandbox → verify → trace → memory
- Tool Bus v1 with contract-bound tools
- Repository Agent Loop with deterministic and optional LLM planning (proposal-only)
- Sandbox profiles with apply-time hard-backend auto-selection
- Demo harness with honest evidence generation
- CI workflow targeting Python 3.11 and 3.12
- `alpha-seal` CLI for repeatable readiness checks

## What this alpha is not

- Not a general autonomous coding agent (patch synthesis is narrow/deterministic)
- Not LLM patch synthesis or vendor tool-calling
- Not production-grade isolation without bubblewrap/docker
- Not multi-agent orchestration, UI, or network/delete/git-push tools
- Not memory canonization or verified long-term learning
- Not a PyPI-published distribution (yet)

## Core proven loop

```
Objective → bounded context → plan (deterministic or LLM proposal)
  → RepoPlanValidator → approval preview → governed patch (Tool Bus)
  → sandboxed test execution → trace → praxis candidates → report/evidence
```

Demonstrated by:

- `tests/test_p020_demo_seal.py` — governed `buggy_calculator` end-to-end (restricted_local)
- `tests/test_repo_planner_p021.py` — LLM planning bridge with mock provider
- `python -m agentic_runtime.cli alpha-seal` — compile, docs, tests, coverage gate
