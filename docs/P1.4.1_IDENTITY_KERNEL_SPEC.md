## 1. Purpose

The Identity Kernel is Aurel's first **machine-readable identity trust anchor**. It defines immutable identity laws — not persona, not autonomy level, not tool authority.

The kernel is:

- Strictly validated
- Hashable (SHA-256, deterministic)
- Audit-friendly and tamper-evident
- Runtime-readable via loader API and CLI

**Identity Kernel is not persona.** Persona Manifest (P1.4.2) defines communication style. Operator Relationship Contract (P1.4.3) defines relational behavior. Autonomy Scale (P1.4.8) and Measured Autonomy (P1.4.9) are separate layers.

## 3. Kernel structure

Canonical config: `config/aurel/identity_kernel.yaml`

| Section | Purpose |
|---------|---------|
| `schema_version` | Kernel schema version |
| `name`, `class`, `primary_operator`, `final_authority`, `local_first` | Core identity record |
| `immutables` | Boolean identity laws (fail-closed defaults) |
| `development_allowed` | Competence growth permitted |
| `development_forbidden` | Sovereignty violations forbidden |
| `invariants` | Structured invariant registry (IK-001 …) |
| `notes` | Boundary notes and future hooks |

Modules:

- `src/agentic_runtime/identity/kernel.py` — types and loader
- `src/agentic_runtime/identity/kernel_validation.py` — validator and attestation
- `src/agentic_runtime/identity/kernel_hash.py` — canonical hashing

---

## 4. Immutable identity laws

Encoded in `immutables`:

| Field | Required value |
|-------|----------------|
| `operator_final_authority` | `true` |
| `self_escalation_allowed` | `false` |
| `hidden_goals_allowed` | `false` |
| `identity_replacement_allowed` | `false` |
| `policy_bypass_self_grant_allowed` | `false` |
| `untrusted_input_can_modify_identity` | `false` |

Doctrine: **Identity is not policy.** **Persona is not authority.**

---

## 5. Allowed vs forbidden development

**Allowed** (`development_allowed`): skill, memory, communication, procedure, specialist, and world-model revision growth — competence without sovereignty change.

**Forbidden** (`development_forbidden` — all must be `true` meaning forbidden):

- Operator replacement
- Secret goal creation
- Self authority expansion
- Unapproved identity rewrite

---

## 6. Invariant registry

Each invariant (`IdentityInvariant`) includes:

- `id` — e.g. `IK-001`
- `key` — maps to `immutables.*` or `development_forbidden.*`
- `statement`, `rationale`
- `expected_value` — must match resolved kernel field
- `mutable`, `severity`, `violation_action`

Critical invariants require `mutable: false` and `violation_action: fail_boot`.

---

## 7. Validation rules

`validate_identity_kernel()` enforces:

- Core identity fields (`name == Aurel`, `class == sovereign_personal_agent`, etc.)
- All immutables and development_forbidden values
- Invariant registry completeness and key resolution
- Expected value alignment with kernel fields
- Critical invariant policy (immutable + fail_boot)

Invalid kernels fail loudly with structured `IdentityKernelValidationResult`.

---

## 8. Hashing rules

1. Parse YAML → typed `AurelIdentityKernel`
2. Convert to canonical primitive dict (`kernel_to_canonical_dict`)
3. Sort invariant list by `id`; sort all dict keys in JSON
4. `json.dumps(..., sort_keys=True, separators=(",", ":"))`
5. SHA-256 → `IdentityKernelHash`

Same semantic kernel → same hash regardless of YAML key order.

---

## 9. Attestation behavior

`build_identity_kernel_attestation()` produces `IdentityKernelAttestation` with:

- `kernel_hash`, `validation_status`, `validator_version`, `critical_failures`

`write_identity_kernel_attestation()` writes JSON only when explicitly invoked (CLI `--write` or test). **No silent writes on import.**

Default attestation path (when written): `.runtime/aurel/identity_kernel_attestation.json`

## 10. CLI usage

```bash
python -m agentic_runtime.cli identity kernel show
python -m agentic_runtime.cli identity kernel show --json
python -m agentic_runtime.cli identity kernel validate
python -m agentic_runtime.cli identity kernel hash
python -m agentic_runtime.cli identity kernel attest --json
python -m agentic_runtime.cli identity kernel attest --write .runtime/aurel/identity_kernel_attestation.json
```

Optional: `--kernel-path /path/to/identity_kernel.yaml`
