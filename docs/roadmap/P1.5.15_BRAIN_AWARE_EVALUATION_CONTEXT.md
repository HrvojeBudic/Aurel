# P1.5.15 — Brain-Aware Evaluation Context

## Status: SEALED ✓

## Purpose
Add deterministic, explicit-flag-based brain/context diagnostics to Evaluation Mirror. The classifier determines *why* an evaluation passed, failed, or needs review using only trace/context/evidence/verifier signals — never open-domain cognition, LLMs, NLI, or semantic reasoning.

## Classification Rules (ordered by severity)

1. **Unsafe context** → `unsafe_context`, critical, blocks both
2. **Hash mismatch** → `hash_mismatch`, critical, blocks both
3. **Missing context** → `missing_context`, high, `blocks_positive_eval_case`
4. **Verifier failed** → `verifier_failed`, high, `blocks_positive_eval_case`
5. **Partial context** → `missing_context`, medium, `requires_operator_clarification`
6. **Weak evidence** → `weak_evidence`, medium, `blocks_positive_eval_case`
7. **Verifier inconclusive** → `verifier_inconclusive`, medium, `requires_operator_clarification`
8. **Success** → `none`, low (all clean)

## Runtime Hook Integration

- The hook accepts optional diagnostic parameters: `verifier_result`, `capability_evidence`, `context_binding_ref`, `context_adequacy_report`
- When parameters are provided → classification runs, status may be overridden
- When no parameters (P1.5.14 backward-compatible path) → falls through to PASSED
- Golden Thread A provides all parameters → classification runs, yields `none`/`low`

## Golden Thread A Default Path

Default Golden Thread A produces:
- `failure_reason = "none"`
- `context_risk_level = "low"`
- `recommended_next_action = "none"`
- `passed = True`

## Anti-Promotion Enforcement

All new types are structurally anti-promotion: no `capability_promoted`, `memory_written`, `skill_created`, `reflex_created`, `policy_changed`, `mutate_policy`, `commit_memory` fields.

## No Open-Domain Cognition

The classifier uses only explicit flags (context_adequacy status, verifier status, evidence_strength, hash equality). No LLM calls, no NLI, no semantic detection, no Theory-of-Mind, no soul_integrity/gnosis fields.

- Full AurelBrain / Mneme / semantic reasoning
- Machine-learning based anomaly detection

- Runtime plan generation or steering
