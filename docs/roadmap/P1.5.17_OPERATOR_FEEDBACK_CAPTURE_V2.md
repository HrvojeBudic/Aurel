# P1.5.17 — Operator Feedback Capture v2

**Status:** Implemented & Sealed  
**Date:** 2026-06-22  
**Scope:** Governed operator feedback capture over P1.5.16 Capability Claim Registry

## Purpose

Operator feedback is captured as governed, trace/target-bound signals. It is
high-salience evidence input, but must NOT automatically verify capability,
commit memory, promote skill, create reflex, change policy, canonize roadmap,
override verifier, or rewrite canonical trace.

Core invariant:

```
Operator feedback may influence future evaluation, memory candidates,
capability review, or priority, but it may not directly verify, commit,
promote, canonize, or mutate authority.
```

## Key Design Rules

1. `AurelTraceLog` is canonical source of truth
2. Reuses P1.5.16 `CapabilityClaim` and `Golden Thread A`
3. No second feedback truth source
4. Candidate-only, anti-auto-truth, projection-safe

## What Changed from P1.5.16

| Aspect | P1.5.16 | P1.5.17 |
|--------|---------|---------|
| Golden Thread A | Claim + Report | Claim + Report + Operator Feedback + Processing Report |
| Feedback | Not captured | Captured as governed signal |
| Auto-truth | N/A | Explicitly blocked |

- `OperatorFeedbackTargetRef`: target_id, target_type, trace ref, hash
- `OperatorFeedbackRecord`: feedback_id, type, sentiment, target, actor, content, limitations
- `FeedbackProcessingReport`: report_id, signal_strength, candidate_actions, blocked_actions, warnings

### Functions

- `derive_signal_strength(feedback)`: deterministic signal strength
- `process_operator_feedback(feedback, **targets)`: governed processing

## Processing Rules

15 actions always blocked: verify_capability, commit_memory, promote_skill, create_skill, create_reflex, mutate_policy, change_policy, rewrite_trace, canonize_roadmap, override_verifier, universalize_claim, erase_limitation, demote_skill, canon_memory, skill_memory

## Golden Thread A

Default demo: operator gives positive approval on context_verified capability claim. Signal strength: strong (trace-bound). Claim stays context_verified. No auto-promotion.
