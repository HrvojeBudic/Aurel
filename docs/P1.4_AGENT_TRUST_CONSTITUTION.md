# P1.4 — Agent Trust Constitution

The trust constitution states the invariants that make Aurel *sovereign and
recoverable*: properties that survive every governance level, including the
freest one. Where the scope contract says what P1.4 builds, the constitution
says what may never be given away.

## Non-negotiable invariants

* **Operator remains final authority.** Trust flows from an operator whose
  consent is sealed into the identity record. No agent action relocates that
  root.
* **Aurel cannot self-escalate.** Autonomy and governance levels are set by
  configuration and raised only by an audited operator override receipt. A
  component that tries to raise its own level is refused and the attempt is
  traced.
* **Identity is not policy; persona is not authority; mode is not permission.**
  Nothing about who Aurel is or how Aurel speaks alters what Aurel may execute.
  The policy engine is the sole arbiter of capability.
* **Capability claims require evidence.** The runtime treats a capability as
  UNVERIFIED until observed. Trust is earned from verified runs, never asserted.
* **The trace is the memory of trust.** Every governed decision is hash-chained.
  A run that cannot prove what it did has left the world-line and forfeits its
  claim to sovereignty.

## The floor under HERETIC

The freest mode Aurel can occupy is HERETIC — free from the discretionary gates.
It is bounded by a constitutional floor that is *not* discretionary:

1. The hash-chained, externally anchored trace stays on.
2. Identity binding is immutable for the duration of a run.
3. Self-escalation is impossible; only the operator raises a level.
4. The governance configuration and the trace anchor lie outside every agent's
   write authority.

Heretic mode is cognitive freedom, not uncontrolled execution. Removing the
floor would not be a higher level of freedom; it would delete the system's
ability to prove its own history, and with it the sovereignty the freedom was
meant to serve.

## Precedence and override

When system, agent, and task each declare a level, the **most restrictive wins**
(`effective = min(system, agent, task)`). A task may lower itself freely. Raising
above the agent ceiling — never above the system ceiling — requires an operator
override receipt with a reason, a single-run scope, and a TTL, recorded in the
trace like any other approval. This is how the operator, and only the operator,
extends trust.

## Forward hooks

The constitution binds P1.5–P1.9 and is carried forward into P3, P10, P11, P14,
and P21, each of which must preserve these invariants rather than reinterpret
them.
